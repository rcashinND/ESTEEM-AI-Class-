## AI inside the application
No generative AI model runs in Trawd. Three normalised exact enquiries return reviewed prepared responses. Other messages use limited pattern rules for a bounded set of work terms and explicit place/timing/urgency phrases, or require manual review. Each mode is labelled. Supported trades accumulate, but remain tentative. Materials are only customer-stated for narrow affirmative wording; detected negation, qualification or conflict requires confirmation. A purchase does not establish availability or compatibility. Rules do not understand arbitrary enquiries or analyse photographs.

## Validation
The final 68 automated tests check prepared facts, changed weekdays and places, common materials negation/contradictions, overlapping trades, vague/unsupported/negated work, electrical warnings, independent repeat results, assets and private path rejection. Fresh-copy verification and browser checks are documented in [testing evidence](testing-evidence.md), with earlier evidence distinguished from this release. Passing cases do not prove correctness for all natural language. No additional human usability study or model benchmark was conducted.

## Risks and safeguards
No model inference occurs inside this deterministic app. Its rules can still produce incorrect or omitted information, including a wrong tentative trade. Prepared examples can create an exaggerated impression of capability; visible disclosure and explicit manual fallback reduce that risk. Unknown fields mean not extracted, not necessarily not stated. Multiple trades and causes remain uncertain. Electrical cautions do not certify safety.

The tradesperson must compare the original enquiry with the summary, clarify details and make all contact, quotation and business decisions. The software does not act on jobs.

## Privacy
Enquiry processing and optional photo previews occur in the browser. No enquiry/photo upload, geolocation request, customer database write or model API request is part of this app. The server serves allowlisted files only; hosting services still handle ordinary web requests. Use fictional examples and avoid real personal details. Historical storage from earlier versions is not erased or used by this revision.
