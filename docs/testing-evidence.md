## Before and after

The first classmate changed “next Tuesday” to “next Wednesday” and reported a generic fallback. The same modified input was run against historical GitHub commit `0367e8b` and the revised rules. The historical output read “Not provided” for timing. The later rule output read “next Wednesday” with practical plumbing follow-ups. Current browser replay confirmed Wednesday also survives the handoff. [Raw comparison](evidence/current/before-after-weekday.json)

## Interpretation

These cases support the prototype’s immediate value as a way to structure familiar enquiries, surface missing information and keep a cautious human decision. The broad vague case revealed a misleading mode label even when the fields correctly preserved unknowns. These results establish software behavior on selected inputs. Real triage time, unfamiliar wording and how tradespeople use the brief remain unevaluated.
